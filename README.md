# VISION
### An AI-Powered Accessible World Explorer

**Vision** is an AI-powered project designed to help blind and visually impaired people understand their surroundings and explore information about our planet through artificial intelligence, camera technology, voice interaction, and sound.

## Our Mission

To make the world and scientific information more accessible through AI, camera technology, voice, and sound.

## Project Modules

### 1. Vision Assist

An AI-powered accessibility assistant for blind and visually impaired people.

**Planned Features:**
- Camera-based object recognition.
- AI descriptions of surroundings.
- Text recognition and reading (OCR).
- Voice interaction.
- Location-aware navigation assistance.
- Audio feedback for environmental awareness.

### 2. Vision Earth

An accessible Earth science exploration experience inspired by NASA Space Apps Challenge 2026.

**Planned Features:**
- Explore NASA Earth science information.
- Convert scientific data into sound (sonification).
- Explain scientific patterns through audio.
- Voice-based Earth science exploration.
- Accessible experiences for people who cannot rely on visual information.

## Target Platforms

- Web application.
- Android application.

## Proposed Technology Stack

- React and Vite – Web application.
- React Native / Expo – Potential native Android application.
- Python and FastAPI – Backend.
- AI vision services – Image understanding.
- Speech technologies – Voice interaction.
- NASA open datasets – Earth science information.
- JavaScript audio processing – Sonification.
- Git and GitHub – Version control.

## NASA Space Apps Challenge 2026

**Selected Challenge:** The Earth Information Jukebox

Our goal is to create an accessible experience that connects NASA Earth science visualizations with dynamically generated sounds.

The project will explore how scientific data can be translated into audio so that users can understand Earth's changing systems through sound.

## Development Goals

1. Build a useful AI-powered accessibility assistant.
2. Make Earth science information accessible through sound.
3. Develop web and Android experiences.
4. Create an accessible and user-friendly interface.
5. Demonstrate a working prototype.
6. Test the application with a focus on usability and accessibility.
